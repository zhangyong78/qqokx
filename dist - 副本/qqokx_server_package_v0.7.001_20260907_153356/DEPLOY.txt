QQOKX server package v0.7.001

1. Runtime
- Python 3.11+
- Windows: run RUN.bat for the workbench, RUN_QT.bat for Roll Terminal QT
- RUN_QT.bat automatically installs missing Qt runtime dependencies using the detected Python
- Linux server: this GUI app requires a desktop environment
- Linux Tk install example: sudo apt-get install -y python3-tk
- Optional custom data dir: `python main.py --data-dir D:\qqokx_data`
- Optional environment override: `QQOKX_DATA_DIR=D:\qqokx_data`

3. Runtime data layout
- Default shared data dir: sibling `qqokx_data/` next to the code folder
- Main subfolders: `config/`, `cache/`, `state/`, `logs/`, `reports/`
- First launch will bootstrap legacy `.okx_quant_*`, `logs/`, and `reports/` into the shared data dir

4. Not included
- Shared runtime data directory `../qqokx_data/`
- tests/
- 临时数据目录

5. Upgrade notes
- Preferred: keep the same sibling `qqokx_data/` and replace only the code package
- Or copy the whole `qqokx_data/` directory to the new machine / new version
- Enhanced live strategy sessions can be resumed from the preserved data directory after restart

# 交易汇总：第一阶段

入口仍为本地 Qt 客户端的「交易汇总」，无需安装新依赖。

## 页面与操作

- 新增「分析概览」「合约分析」，原有每日、品种、策略、明细四张表及 CSV / HTML 导出保留。
- API 跟随主窗口；币种、日期共用筛选，支持近 7 / 30 / 90 天和本月。
- 概览日历点击日期进入交易明细；合约日历点击日期筛选本页统计，点击「恢复区间」取消。
- 产品盈亏、累计收益与币种排行采用同一批完整平仓记录。合约表按表头数值排序。
- 当前总权益、资产分布是账户级数据，不随历史日期或币种变为局部账户余额；币种选择仅突出圆环中的对应币种。

## 数据与统计口径

- 本地历史仓位按生命周期去重，金额按完整平仓日归集；部分平仓仍保留在交易明细，但不计入完整仓位统计。不是逐日盯市盈亏，也不保证与 OKX 资产分析数字一致。
- 优先使用 `realizedPnl`，不会重复扣手续费或资金费。缺少净盈亏且无法从已有分项重建时不参与金额合计。
- USDT 直接统计；BTC、ETH、USDC 等结算币种使用当前可用参考汇率折合 USDT，并标注估值。没有汇率则显示未估值，不把原币金额误标成 U。
- 胜负率以有可用净盈亏的完整仓位为分母；零盈亏为持平。平均盈亏比为平均盈利 / 平均亏损绝对值，与总盈利 / 总亏损绝对值分开展示。
- 风险回报为有效初始风险金样本的平均 R；缺风险金、开仓时间或收益率时相应指标显示 `--`。
- 时间统一为北京时间。收益率是已结算净盈亏 / 期初账户权益的近似比例（USD≈USDT），不包含浮盈、不是剔除出入金后的账户收益率。缺少期初附近权益快照则不计算。

## 权益采样与运行

- 复用共享实时账户服务，每次新鲜 REST 账户校验后尝试存储，每个 API / 实盘模拟环境每小时至多一条，不因查看页面重复采样。
- 保存在现有数据目录的 `state/history/<API>/<环境>/account_equity_curve.json`；账户权益原始单位为 USD，范围仅为交易账户，不包含资金或金融账户。
- 客户端未连接期间不补造数据；走势图显示采样起点，超过两小时缺口断开。
- 历史缓存读取在后台完成，报表读取不回写仓位缓存。切换 API 后忽略旧后台结果，避免账户数据串用。
- 本阶段未增加下单、平仓或自动交易行为。测试未向实盘发送交易请求，也未重启用户正在运行的客户端。

## 第二阶段状态与限制

已接入账户账单、充值提现账单和现货成交 FIFO 估算；如果本地成交历史不足以还原库存，仍显示缺少库存/汇率并不计入合计。
充值提现按各自原币展示，不把 BTC、USDT 等不同币种相加；交易收益仍只在有可靠 USDT 估值时进入 USDT 合计。
历史资产补齐、完整跨账户资金流调整收益率和更长时间范围的账单归档仍需后续补充。

## 验证

相关单元测试覆盖币种估值、零盈亏、部分平仓、时区、指标对账、账户隔离、小时采样与导出；Qt 离屏测试覆盖筛选联动、排序、后台过期结果、空数据和实际页面渲染。

`tests_artifacts/trade_analytics/` 下的预览截图使用明确的测试数据，不是真实账户收益。

启用行情中转

本地先直连 OKX；网络故障时改由你的服务器代取公开行情。

只有服务器已配置有效 HTTPS 证书并监听 8765 端口时才能这样填。
这里必须填写与服务器端完全相同的专用行情密钥。
“Great”不能直接用作密钥。它只有 5 个字符，软件要求 32–128 位随机字符。请在服务器生成随机密钥，将同一个密钥放入服务器的 MARKET_RELAY_TOKEN 环境变量和本地这个访问密钥框。不要用交易所 API 密钥。
服务器地址要留意 HTTPS 证书。直接用 IP 地址时，证书必须包含 43.132.213.112。如果证书签发给域名，就把本框改填该域名，例如 https://relay.example.com。
服务器端：单独启动行情中转服务（HTTPS 直连监听或由 HTTPS 反向代理转发到服务器本机 8765 端口）。启动/停止这个服务就是服务器端的开/关，现有策略不用为此切换程序版本。
本地端：勾选开关，填服务 HTTPS 地址和同一密钥，点击“保存行情中转”，重启本地 QQOKX。

此页仅为填写示意，不会连接服务器、启动服务或保存凭证。当前服务器端还没有 GUI 复选框。

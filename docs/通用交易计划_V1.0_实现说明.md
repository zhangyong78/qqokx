# 通用交易计划 V1.0：实现说明

本版本先把用户描述转换为可计算、无未来数据的规则引擎，代码位于
`okx_quant/strategies/general_trade_plan.py`。模块只产生信号和计划层退出判定，
不直接下单，也不会改变现有小雨策略或其他实盘策略。

## 规则客观化

### 1. 趋势交易（日线 / 4小时）

- 默认均线：EMA20、EMA30、EMA40。
- 多头回踩：当前已收盘K线收盘价站在三条均线上方，最低价触及任意均线的
  `0.25 × ATR` 容差，且收阳线。
- 空头反弹：当前已收盘K线收盘价位于三条均线下方，最高价触及任意均线的
  `0.25 × ATR` 容差，且收阴线。
- 有力度突破：实体长度至少为 `0.80 × ATR`，并首次收盘站上/跌破三条均线。

### 2. 短线交易（30分钟）

- 默认 EMA20。
- 价格在均线上方回踩并收阳线做多；价格在均线下方反弹并收阴线做空。
- 回踩/反弹同样使用 `0.25 × ATR` 容差。

### 3. 箱体交易

- 默认使用前20根已收盘K线的最高价和最低价作为箱体上下沿。
- 箱体宽度必须处于 `1.0～6.0 × ATR`；不满足时不交易。
- 触及下沿后收阳线做多，触及上沿后收阴线做空。
- 箱体中部不交易。

### 4. 震荡突破

- 先用前20根已收盘K线确定箱体。
- 收盘突破上沿/跌破下沿至少 `0.10 × ATR`，同时站上/跌破三条均线，且实体至少
  `0.80 × ATR`，才生成突破信号。

## 执行约束

- 信号只使用已确认K线；调用方应在下一根K线执行。
- `should_exit_general_trade_plan()` 只负责计划层的不利信号退出：
  趋势/短线为收盘反向穿越参考EMA，箱体为有效跌破/突破边界，突破策略为重新回到箱体内。
- 普通止损、移动止损、费用和仓位风险应继续复用公共保护模块。
- “有力度”“回踩”“箱体”已变成参数，不代表这些默认值已经经过品种和周期优化。

## 尚未做的接入

本次先完成规则引擎和单元测试，尚未把它加入回测窗口策略列表，也没有同步到实盘入口。
原因是箱体识别和“均线走平”的主观定义需要先经过回测确认；直接接入实盘会把未经验证的
默认阈值扩大到所有币种。下一步可以把四种模式分别加入回测策略列表，跑完数据后再决定
是否开放实盘。

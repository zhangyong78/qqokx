# BTC EMA 动态委托做多：1R 后 EMA55 走平离场

## 目标

使用本地 BTC-USDT-SWAP 1H 全量已确认 K 线，按当前 BTC EMA 动态委托做多最佳参数和每笔固定风险 100U，记录基线结果；再比较新增的 1R 后 EMA55 走平离场版本。

## 固定回测口径

- 固定风险：100U/笔；初始资金 10,000U；非复利。
- 信号基于已收盘 K 线；动态委托开仓、费用、滑点和其他默认保护规则保持基线一致。
- 开仓按当前 BTC 最佳参数：EMA21 趋势确认、EMA55 动态回踩委托、ATR10、ATR 止损倍数 2、入场斜率过滤关闭，以及当前默认的动态保护阶梯。
- 开仓为 Maker，平仓为 Taker；所有比较使用同一份本地缓存和同一组成本参数。

## 对比版本

### 基线

不启用新增的走平离场。其余参数完全使用当前 BTC 最佳参数。

### 1R 后 EMA55 走平离场

在基线之上新增且仅新增以下规则：

1. 多单在持仓期间曾达到至少 1R，规则被激活。
2. 随后任一已收盘 1H K 满足 `EMA55[t] <= EMA55[t-1]`，即 EMA55 走平或下行。
3. 按该根 K 的收盘价平仓，并计入 Taker 手续费和已有退出滑点。
4. 初始止损、动态保护阶梯和已有平仓规则优先级维持回测引擎当前顺序；新增规则只在仓位尚未被其他规则平掉时执行。

这严格镜像 BTC EMA55 斜率做空策略的走平定义（空头为 `EMA55[t] >= EMA55[t-1]`）。

## 输出与判断

报告必须并排给出基线和新增规则版本的参数快照、数据区间、K 线数量、交易数、总盈亏、收益率、最大回撤、PF、平均 R、胜率、年度拆分和平仓原因。另输出逐笔交易明细，标记由新增规则触发的交易，方便审计差异。

本轮只做 BTC 回测研究与报告，不改动当前实盘默认参数，也不把新规则写入最佳参数包。是否采用以全量结果、年度稳定性和回撤改善的综合比较为准，避免仅按总收益挑选。

## 验证

- 为新增规则写最小单元测试：未到 1R 不触发；到 1R 后 EMA55 上行不触发；到 1R 后 EMA55 走平和下行均触发。
- 运行相关回测测试及研究脚本。
- 确认两版本使用同一数据范围、固定 100U 风险和一致成本。

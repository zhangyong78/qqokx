# 半自动操盘台设计

## 目标

新增独立的“半自动操盘台”。交易员人工判断行情后，把一个或多个当前策略配置加入同一个操盘组合；每个策略仅执行一次，结束后不自动再次开仓。不同策略、币种、周期和多空方向的已结算交易归入同一组合账本，并以组合虚拟资金生成连续资金曲线和统计。

## 与交易员管理台的边界

- 交易员管理台：固定策略模板、额度格和自动补位。
- 半自动操盘台：人工每次选择策略，一次性执行任务，绝不自动补位。
- 两者共用策略启动、订单执行、平仓归因、普通策略交易账本和实时 K 线渲染能力；互不改变对方的状态或统计。

## 核心对象

### 操盘组合

`SemiAutoPoolRecord` 是长期身份，字段包括组合编号、名称、API 配置、初始虚拟资金、创建/更新时间和状态。组合可以跨币种和策略；虚拟资金只统计归属于该组合的已结算净盈亏。

### 一次性任务

`SemiAutoTaskRecord` 绑定一个组合和一个策略配置快照，字段包括任务编号、策略/币种/方向/周期、启动模式、会话编号、状态、开始/结束时间、结束原因和关联账本记录编号。

支持两种模式：

1. `evaluate_once`（单次判断）：策略只评估启动时的首个已确认 K 线；没有入场计划时结束为“本次无信号”。若产生委托，继续管理这一次委托；委托失效且未成交时结束，成交后管理至平仓结算后结束。
2. `wait_one`（等待一单）：持续等待后续信号；未成交委托失效后继续等待；首次开仓成交后管理至平仓结算后结束。

任务状态：`queued`、`running`、`opened`、`settling`、`completed_no_signal`、`completed_closed`、`blocked_conflict`、`cancelled`、`failed`。

## 并发与安全

- 可同时启动多个币种、策略和方向的任务。
- 同一币种同一方向允许同时等待或挂单。
- 第一个开仓成交的任务获得“币种 + 方向”锁；系统停止并撤销其余同币种同方向任务的未成交委托，任务状态写为 `blocked_conflict`，原因写为“仓位冲突未执行”。
- 同币种反向任务仅在双向持仓模式允许；单向持仓模式在启动前拒绝。
- 若两个同方向任务在撤单完成前均成交，系统停止所有尚未成交任务并将两个任务标记为需要人工核对；不自动合并或猜测归因。

## 结算、暂停与恢复

- 任务看到开仓成交后更新为 `opened` 并建立方向锁。
- 止盈、止损、手工平仓或交易所其他平仓后，任务先进入 `settling`。
- 只有现有成交归因写入交易账本后，任务才变为 `completed_closed`；随后安全停止策略会话，防止同一策略评估下一次信号。
- 所有任务结束时，组合状态显示“待人工选择下一策略”。组合本身不停止、不删除，也不会自动新建任务。
- 用户可随时取消尚未开仓的任务；有仓位任务仍使用现有人工平仓流程，结算后结束。

## 账本、资金曲线与统计

现有 `StrategyTradeLedgerRecord` 新增 `semi_auto_pool_id` 和 `semi_auto_task_id`。这两个字段也写入持久化 JSON，因此应用重启后仍可按组合恢复账本和复盘。

组合总账本按平仓时间倒序显示每笔交易的币种、策略、多空、开平仓时间/价格、数量、净盈亏、平仓原因和任务状态。

组合资金曲线采用：

```text
组合虚拟资金 = 初始虚拟资金 + 已结算交易净盈亏累计值
```

不使用 API 的真实账户权益做收益统计，以免充值、提现、手工交易和其他机器人污染结果。界面可单独显示真实账户权益参考值，但不纳入该曲线。

统计至少包括交易数、胜/负数、胜率、累计净盈亏、平均盈利、平均亏损、盈亏比（平均盈利 / 平均亏损绝对值）、最大连续亏损和按策略/币种的净盈亏分组。

## K 线复盘

从组合账本选择币种和周期后，读取该币种 K 线，并在一张图上叠加该组合所有任务的开仓和平仓标记。标记携带策略名称、方向、成交时间、成交价格和本次净盈亏；不依赖原会话仍在运行。

## 页面范围

“半自动操盘台”窗口提供：

- 组合选择/新建、名称、API 和初始虚拟资金；
- “加入当前策略”：将策略启动器当前配置快照加入选中组合；重复操作即可加入多个不同策略；
- 任务列表：策略、币种、方向、周期、模式、状态、会话、结束原因；
- 启动选中任务、取消未开仓任务、打开组合总账本、按币种打开复盘图；
- 组合统计摘要和按策略/币种汇总。

首版不提供独立的策略模板库、自动信号推荐、真实账户权益自动对账或跨 API 组合。

## 验收

1. 同一组合可启动多个不同策略，且每个任务只执行一次。
2. 单次判断无信号时自动结束；等待一单无信号时继续等待。
3. 首次成交并平仓结算后，任务不会再评估或开下一笔。
4. 同币种同方向首单成交后，其余任务标记为仓位冲突未执行。
5. 不同币种或允许的相反方向任务可独立执行。
6. 组合账本在重启后仍连续，虚拟资金曲线和统计只统计本组合交易。
7. 同一币种复盘图叠加该组合全部策略的多空开平仓记录。
8. 现有交易员管理台自动补位行为和普通策略账本不变。

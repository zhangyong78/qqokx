# 半自动操盘台：内置策略库选择设计

## 目标

半自动操盘台不再从主策略工作台读取“当前策略”。用户应当直接在半自动操盘台选择已注册的内置策略，填写本次实盘参数，生成一条一次性任务并启动。

每个任务只执行一次：按任务模式等待或判断信号，首次成交后管理至平仓结算，随后自动停止，绝不进入下一次开仓。

## 不变的边界

- 组合、连续账本、K 线复盘、统计、持仓冲突与重启安全处理保持现有行为。
- 仅提供已注册的内置策略；不执行任意 Python 脚本，不新增外部脚本加载能力。
- 任务保存完整策略参数快照；后续修改策略库默认值不影响已加入任务。
- 普通实盘策略启动和交易员管理台不改变。

## 用户流程

1. 打开“工具 → 半自动操盘台”，创建或选择操盘组合。
2. 点击“从策略库添加”。
3. 在弹窗中选择内置策略，例如“EMA 动态委托做多”或“EMA55 斜率做空”。
4. 弹窗显示与正常实盘启动一致的策略参数：API、币种、K 线周期、方向、仓位模式、资金/数量、止损止盈及策略专属参数。
5. 确认后，将参数序列化为该组合的一条 `SemiAutoTaskRecord`；用户选择“等待一单”或“单次判断”。
6. 选中任务点击“启动选中任务”。首次交易平仓并写入账本后，任务自动停止。

## 界面

半自动操盘台操作栏将移除“加入当前策略”，替换为“从策略库添加”。

策略选择弹窗分两步：

1. 策略列表：只展示 `STRATEGY_DEFINITIONS` 中可启动的内置策略及其默认方向说明。
2. 参数确认：复用现有策略参数构建与校验规则，按所选策略显示适用字段。确认按钮文本为“加入一次性任务”。

弹窗关闭、参数校验失败或未选择组合时，不创建任务。

## 实现边界

- 提取可复用的“从内置策略定义生成策略配置”与“参数校验”入口，避免复制一套实盘参数含义。
- 半自动窗口通过回调获取策略库定义和创建任务所需的配置快照，不再接收 `current_template_factory`。
- 任务启动仍复用 `_start_strategy_session`，并保留 `semi_auto_pool_id`、`semi_auto_task_id`、`semi_auto_mode` 上下文。
- 只允许策略库中已经支持正常实盘启动的策略进入选择器；不支持的策略显示原因且不能确认。

## 错误与安全

- 组合未选择：提示先选择操盘组合。
- API 缺失或参数不合法：阻止加入任务，并显示现有参数校验错误。
- 净持仓模式下同币种相反方向活动任务：保留现有启动前拦截。
- 单次任务的无信号、首次成交、结算和重启处理保持现有状态机。

## 验收

1. 不改变主策略工作台当前选择时，仍可从半自动操盘台选择任一内置策略并创建任务。
2. 任务列表显示选中的策略、币种、方向与周期；保存后重启仍保留其参数快照。
3. 启动后，任务仍遵守“等待一单”或“单次判断”，成交并平仓后不再开下一单。
4. 原“加入当前策略”入口不存在。
5. 普通实盘策略启动、交易员管理台、半自动账本与复盘回归测试保持通过。

# Qt 量化交易终端导航与默认工作区设计

日期：2026-07-12  
状态：界面方向已选定，待用户审核书面规范

## 1. 目标

把当前分散的菜单和多个主窗口入口整理为一个成熟交易客户端式工作台：

- 软件启动后默认进入 K 线工作区，并立即显示图表。
- 账户持仓、K 线和专业套利作为同一主窗口中的三个一级工作区。
- API、模拟/实盘环境、连接状态和本地任务状态提升到全局顶栏。
- K 线形态信号默认不启用，减少首屏噪声。
- 切换页面或 API 不影响已运行的 RR、条件单和短时套利任务。
- 低频功能进入清晰的工具菜单，避免相同入口在多个菜单中重复出现。

本次只调整 Qt 本地终端的信息架构与交互，不改变 Tk/服务端的长期策略、回测和实盘执行链路。

## 2. 总体布局

主窗口固定分为三层：

1. 全局顶栏：页面导航、全局 API、连接状态、任务状态和设置。
2. 页面工具栏：只显示当前工作区相关的操作。
3. 中央工作区：承载 K 线、持仓、专业套利或工具页面。

主窗口不再依赖“模块导航”“K线分析”“系统”等传统菜单来完成核心页面切换。

## 3. 全局顶栏

### 3.1 左侧一级入口

按固定顺序显示：

1. `K线`
2. `持仓`
3. `专业套利`
4. `交易工具 ▾`
5. `期权工具 ▾`

前三项是高频、常驻、单窗口页面。点击后切换中央工作区，不创建新的主窗口。

### 3.2 交易工具菜单

- 无限下单
- 后续新增的临时交易工具

划线、水平线和 RR 属于 K 线工作区的上下文工具，不再作为重复的全局“划线交易台”入口。自动通道不保留独立页面或菜单入口；第一期以 K 线内默认关闭的“自动箱体 / 通道”分析模块呈现，后续继续在此扩展趋势线、三角形等研究能力。

需要持续监控或下单的工具优先显示在主窗口中央工作区。只有纯计算、纯查看且无需持续任务状态的工具，才允许使用简单辅助窗口。

### 3.3 期权工具菜单

- 期权策略计算器
- Deribit 波动率

展期建议保留在持仓页选中期权后的上下文操作中，避免与持仓对象脱节。

### 3.4 右侧全局状态

从左到右显示：

- 公共行情连接状态，例如 `● 行情在线`
- 当前环境与 API，例如 `模拟 · moni ▾`
- 本地任务摘要，例如 `任务 3 ▾`
- 设置入口 `⚙`

设置菜单包含：

- API 配置管理
- 数据目录与路径
- 日志
- 界面设置
- 版本信息

## 4. 默认启动行为

- 默认工作区：`K线`
- 默认 API：配置中存在 `moni` 时优先使用 `moni`；不存在时才回退到已选或首个可用配置
- 默认标的：延用当前持久化标的；没有记录时使用 `BTC-USDT-SWAP`
- 默认图表：显示
- 默认周期：延用当前持久化周期；没有记录时使用 `4H`
- EMA15：开启
- SMA50：开启
- 1H 形态：关闭
- 4H 形态：关闭
- 1D 形态：关闭
- 碰均线形态过滤：关闭

为了减少首屏等待，启动时优先创建 K 线页面。持仓和专业套利页面在首次点击时再创建，创建后保留页面实例与用户现场。

## 5. K 线页面工具栏

第二行只保留与当前图表直接相关的高频项目：

- 合约/交易对切换
- 周期快捷按钮
- EMA15
- SMA50
- `形态：关/开`
- 双图入口
- K 线数量
- 图表设置

低频显示项收入“图表设置”：

- 1H/4H/1D 形态细分
- 碰均线过滤
- 平均 K 线
- K 线反转
- 本地数据优先
- 图表范围
- 自动刷新

“隐藏图表”继续保留，但默认不隐藏。隐藏图表或切换到其他页面，只暂停图表渲染和非必要刷新，不停止 RR 与条件单监控。

K 线左侧面板负责当前标的工具：

- 画线与水平线
- RR 条件单
- 临时条件单
- 当前标的任务列表

委托、持仓和任务以可展开抽屉显示，关闭抽屉后不占用图表空间。

## 6. API 切换与任务绑定

顶部 API 表示“当前查看账户和新操作账户”，不表示所有后台任务的账户。

### 6.1 切换后的行为

- 持仓页加载所选 API 的持仓、委托和历史数据。
- K 线页新建的 RR、条件单和手动订单使用所选 API。
- 专业套利页新建的套利任务使用所选 API。
- 用户可以切换到其他 API 查看持仓并执行手动平仓。

### 6.2 已运行任务

- 任务创建时记录不可变的 API Profile 标识。
- 顶部 API 切换不迁移、不暂停、不重启已运行任务。
- 任务摘要按 API 分组，例如 `moni：RR 2｜api2：条件单 1`。
- 任务详情、成交回报和错误提示必须显示实际绑定的 API。

### 6.3 手动交易安全

- 下单或平仓动作开始时捕获当前 API，后续请求不能因界面切换而改发到另一个 API。
- 确认框明确显示 API、环境、合约、方向和数量。
- 操作完成提示明确显示实际执行 API。
- 切换 API 后，旧账户尚未完成的单次请求仍由旧 API 完成，但不会影响新页面的查看状态。

## 7. 持仓与专业套利页面

### 7.1 持仓页

页面内移除重复 API 下拉框，使用全局顶栏选择。

页面工具栏保留：

- 刷新
- 账户信息
- 展开持仓详情
- 折叠历史区域
- 平仓选中
- 编辑备注
- 期权保护
- 展期建议
- 列设置

### 7.2 专业套利页

页面内移除重复 API 下拉框，使用全局顶栏选择。

套利任务创建时绑定当前 API；切换 API 后仍可观察原任务，同时新建任务使用新的当前 API。页面需要在任务卡片上持续显示绑定账户。

## 8. 页面与窗口规则

- K 线、持仓、专业套利：同一主窗口内切换，页面现场持久保留。
- 持续监控或交易工具：优先在中央工作区打开，不另开主窗口。
- 期权计算器、波动率分析等纯分析工具：允许打开一个简化辅助窗口。
- 辅助窗口不复制全局导航，也不承担长期后台任务。
- 切换页面不销毁页面实例，不停止本地任务。
- 关闭整个程序时，如存在本地运行任务，继续显示统一的关闭确认。

## 9. 状态与异常显示

- 公共行情和私有账户连接分开表达，避免一个“在线”掩盖部分断线。
- API 不可用或未解锁时，公共 K 线仍可查看；交易按钮禁用并说明原因。
- 页面首次加载显示局部骨架或加载状态，不阻塞整个主窗口。
- 页面加载失败只影响当前页面，不影响顶栏、其他页面和运行中任务。
- 顶栏任务摘要始终可见，用于确认隐藏页面中的任务仍在运行。

## 10. 当前入口到新入口的映射

| 当前入口 | 新入口 |
| --- | --- |
| 模块导航 → 账户持仓主页 | 一级入口 `持仓` |
| K线分析 → 打开 K 线分析 | 一级入口 `K线`，并作为默认页 |
| 模块导航 → 专业套利终端 | 一级入口 `专业套利` |
| 模块导航 → 无限下单 | `交易工具` |
| 模块导航 → 自动通道 | 取消独立入口，作为 K 线“自动通道”分析模块 |
| 模块导航 → 划线交易台 | 合并进 K 线左侧工具 |
| 期权 → 期权策略计算器 | `期权工具` |
| 期权 → Deribit 波动率 | `期权工具` |
| 系统 → 目录、日志、版本 | 顶栏 `⚙` |
| 各页面内部 API 下拉框 | 顶栏全局 API |

## 11. 验收标准

1. 启动后无需点击菜单即可看到 K 线图。
2. 1H、4H、1D 形态默认均为关闭状态。
3. 顶栏可在 K 线、持仓、专业套利之间切换，且不创建第二个主窗口。
4. 页面切换后再返回，标的、周期、滚动位置、输入内容和任务状态仍保留。
5. API 切换后可以查看和操作新账户，原 API 的运行任务不受影响。
6. 新任务绑定切换后的 API，旧任务仍显示原 API。
7. 手动平仓确认框和结果提示均显示实际 API。
8. 隐藏 K 线图或切换页面不会停止 RR、条件单或套利任务。
9. 所有现有功能都有唯一、清晰的入口，不出现核心功能无处返回的情况。
10. 公共行情断线、私有账户断线、API 锁定三种状态可以被用户区分。

## 12. 不在本次范围

- 不重写 Tk/服务端策略引擎。
- 不改变回测和长期实盘的启动方式。
- 不迁移或转换共享数据目录。
- 不修改 RR、条件单、套利策略的计算和执行规则。
- 不新增多窗口、多屏联动或可拖拽停靠系统。
